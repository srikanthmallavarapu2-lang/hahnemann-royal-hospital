## 🚀 Running Locally
Simply open `index.html` in any modern web browser:
```bash
# Clone the repository
git clone https://github.com/<your-username>/hospital-website.git

# Open directly in browser
start index.html
```
Or serve with any static web server:
```bash
npx serve .
```
